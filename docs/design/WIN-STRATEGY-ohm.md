## Special-award lane: name Headless Hero, and only Headless Hero

Equality Group Champion is contested by all 22 Earthforce entries by definition; Accessibility Excellence draws teams whose entire product is accessibility. Headless Hero sits in Ohm's own product category with an estimated 0–2 serious contenders — least contested, best fit. But the fit is no longer verbatim: Ohm audits agent *design*, not runtime behavior, and a dedicated eval-harness entry fits the award text more literally. Defend the lane with this exact framing in the observability submission answer:

> "Ohm is pre-production agent observability — the inspection that happens before the incident. It discovers every agent in the org, scores its design against four measurable waste signals, and persists every finding as an auditable record with its evidence, its confidence, and its uncertainty band. During the audit you can watch it work: a live progress log, the agent narrating each stage, and — because Ohm is itself an Agentforce agent — a log of its own action invocations as it runs. Every number the agent speaks is computed in deterministic Apex and written to a record first; the model is architecturally incapable of inventing a metric. That is observability ensuring an agent performs reliably, transparently, and safely — applied to the entire fleet, including itself. Ohm passed its own audit; the report is in the org."

Target outcome: **2nd/3rd podium + Headless Hero.** Floor if the heart-patch fails or Task 0 slips: Headless Hero alone — which is why the agent-surface spike and the hook rewrite are the two highest-leverage hours remaining before Sep 6.
